## Installation Quick Start

```bash
# Install Claude Code
npm install -g @anthropic-ai/claude-code

# Navigate to your project
cd your-awesome-project

# Start coding with Claude
claude
```

## Key Features

- **Build features from descriptions**: Tell Claude what you want to build in plain English
- **Debug and fix issues**: Describe a bug or paste an error message for analysis
- **Navigate any codebase**: Ask anything about your team's codebase
- **Automate tedious tasks**: Fix lint issues, resolve merge conflicts, write release notes

## Why Claude Code?

- **Works in your terminal**: Not another chat window or IDE
- **Takes action**: Directly edit files, run commands, and create commits
- **Unix philosophy**: Composable and scriptable
- **Enterprise-ready**: Use Anthropic's API, or host on AWS or GCP
