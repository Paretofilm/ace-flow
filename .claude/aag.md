# /aag - ACE-Agent Alias

This is a short alias for the `/ace-agent` command.

**Usage**: `/aag [arguments]`

**Examples**:
- `/aag research "auth patterns"` → Launch research agent
- `/aag validate --strict` → Run validation agent
- `/aag list` → List all available agents

For full documentation, see: `/ace-agent`
