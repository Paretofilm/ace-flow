## 🚀 **How to Use in Obsidian**

### Step 1: Open the Vault
1. Download/install Obsidian from https://obsidian.md
2. Open Obsidian
3. Click "Open folder as vault"
4. Select the `amplify-obsidian-vault` directory

### Step 2: Start Exploring
- **Begin with**: Open `README.md` for overview
- **New to Amplify?**: Go to `Learning-Paths/Complete-Beginner.md`
- **Need quick help?**: Check `Quick-Reference/` folder
- **Visual learner?**: Open Graph View (Ctrl/Cmd + G)

### Step 3: Optimal Obsidian Settings
The vault comes pre-configured, but you can enhance further:
- **Enable**: Graph view, backlinks, tag pane
- **Install**: Dataview plugin for dynamic queries
- **Theme**: Dark theme works great with the structure
- **Hotkeys**: Cmd/Ctrl + O (quick switcher), Cmd/Ctrl + Shift + F (search)
