# Configure your application

## Configure your application

Add Amplify to your app with `yarn` or `npm`:

```bash
npm install aws-amplify
```

In your app's entry point i.e. App.ts or App.js, import and load the configuration file:

```javascript
Amplify.configure(config);
```
