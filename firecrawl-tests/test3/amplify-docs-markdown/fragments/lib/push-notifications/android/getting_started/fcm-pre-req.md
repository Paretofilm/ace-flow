# Documentation

Push Notifications are delivered via Firebase Cloud Messaging (FCM). In order to use FCM, you need to register your app on the Firebase console. See [Setting up push notification services](/gen1/[platform]/build-a-backend/push-notifications/set-up-push-service/) for more information.
