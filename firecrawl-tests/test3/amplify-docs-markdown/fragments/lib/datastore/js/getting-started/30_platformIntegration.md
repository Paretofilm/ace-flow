# Documentation

To get started, first create a new React app with [vite](https://vitejs.dev/guide/) using the following commands:

```sh
npm create vite@latest
✔ Project name: amplify-datastore
✔ Select a framework: › React
✔ Select a variant: › JavaScript

cd amplify-datastore
```
