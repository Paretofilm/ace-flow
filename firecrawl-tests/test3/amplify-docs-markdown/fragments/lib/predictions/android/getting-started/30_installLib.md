# Documentation

Expand **Gradle Scripts**, open **build.gradle (Module :app)**. You will already have configured Amplify by following the steps in the [Project Setup walkthrough](/gen1/[platform]/start/project-setup/create-application/).

Add Predictions by adding these libraries into the `dependencies` block:

```groovy
dependencies 
```

`aws-auth-cognito` provides authentication for the backend services used by `aws-predictions`.

Click **Sync Now**.
