# Documentation

Upon completion, `amplifyconfiguration.json` will be updated to reference a newly provisioned S3 bucket.  Note that this file should already be a part of your project if you followed the [Project setup walkthrough](/gen1/[platform]/prev/start/project-setup/create-application/).
