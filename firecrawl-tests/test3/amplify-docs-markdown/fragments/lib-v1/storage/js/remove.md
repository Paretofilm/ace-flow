# Public level remove

Delete stored data from the storage bucket.

## Public level remove

```javascript
await Storage.remove('test.txt');
```

## Protected level remove

```javascript
await Storage.remove('test.txt', );
```

## Private level remove

```javascript
await Storage.remove('test.txt', );
```
