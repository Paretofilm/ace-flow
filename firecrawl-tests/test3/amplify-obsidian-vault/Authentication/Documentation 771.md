# Documentation

If you are not using the Amplify CLI, a Cognito User Pool and Identity Pool can be used by referencing them in your `amplifyconfiguration.json` file.

```json

                },
                "CredentialsProvider": 
                    }
                },
                "CognitoUserPool": 
                },
                "Auth": 
                    }
                }
            }
        }
    }
}
```
