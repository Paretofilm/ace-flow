# In your app configuration

## In your app configuration

Amplify Geo is dependent on your Amplify Auth category. If it is not already configured, then you will need to [configure it](/gen1/[platform]/build-a-backend/auth/existing-resources) as well.

Existing Amazon Location Service resources can be used with the Amplify Libraries by adding information about the resources to your `amplifyconfiguration.json` file.
