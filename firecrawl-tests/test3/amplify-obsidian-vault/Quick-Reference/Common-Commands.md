# ⚡ AWS Amplify CLI - Common Commands

## 🛠️ Project Setup
```bash
npm install -g @aws-amplify/cli
amplify configure
amplify init
```

## 🔐 Authentication
```bash
amplify add auth
amplify push
```

## 📊 API & Database
```bash
amplify add api
amplify add storage
amplify push
```

## 🚀 Deployment
```bash
amplify add hosting
amplify publish
```

## 🔍 Status & Info
```bash
amplify status
amplify console
amplify env list
```
