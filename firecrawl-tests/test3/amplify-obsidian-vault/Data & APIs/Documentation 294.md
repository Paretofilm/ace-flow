# Documentation

The `amplify add api` command adds a new `AmplifyConfig` group to your Xcode project. It will contain the following files:

- `AmplifyConfig/`
  - `amplifyconfiguration.json`
  - `awsconfiguration.json`
  - `schema.graphql`
