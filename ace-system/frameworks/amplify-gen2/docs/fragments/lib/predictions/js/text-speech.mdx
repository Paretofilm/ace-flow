## Set up the backend

If you haven't already done so, run `# Legacy command removed - use npm create amplify@latest` inside your project and then `# Legacy command removed - use defineAuth(), defineData(), etc.` (we recommend selecting the *default configuration*).

Run `# Legacy command removed - use defineAuth(), defineData(), etc.` and select **Convert**. Then use the following answers:

```console
? What would you like to convert? (Use arrow keys)
  Translate text into a different language 
> Generate speech audio from text 
  Transcribe text from audio 
  
? Who should have access? Auth and Guest users
```

Now run `# Legacy command removed - use npx ampx sandbox` which will generate your `amplifyconfiguration.json` and create resources in the cloud. You can now either add this to your backend or skip and add more features to your app.

Services used: Amazon Polly

## Working with the API

Generate an audio buffer for playback from a text input.

```javascript
import { Predictions } from '@aws-amplify/predictions';

Predictions.convert({
  textToSpeech: {
    source: {
      text: textToGenerateSpeech
    },
    voiceId: "Amy" // default configured on amplifyconfiguration.json
  }
})
.then(result => console.log({ result }))
.catch(err => console.log({ err }));
```
To view the complete list of voiceId options refer to [Voices in Amazon Polly](https://docs.aws.amazon.com/polly/latest/dg/voicelist.html).
